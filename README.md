# Log Anomaly + Root Cause Analysis

A metrics-based anomaly detection system that compares
statistical baselines with machine learning models and
ranks probable root causes of detected incidents.

## Planned Features

- Synthetic telemetry generation for three services
- Controlled injection of four fault categories
- Statistical baseline vs. ML detector evaluation
- Root-cause ranking with supporting evidence
- FastAPI backend and PostgreSQL persistence

Requirements and architecture planning.
